# WordCamp US

This folder holds every edition of WordCamp US. Keep it year-free.

- [theme.js](theme.js): default colors, style notes and layout choices.
- [artwork.js](artwork.js): original SVG decorations and event headings.
- [fonts/](fonts/): pinned fonts, original licenses and [edition face selections/source records](fonts/manifest.json).
- [event.js](event.js): edition IDs, official links, confirmed details and factual check dates.

## Existing treatment

Open Sans 300/400/600 with blue/white coming-soon styling. The design is provisional; dates and location remain unconfirmed.

These observations date to 2026-10-03, not a new review of the official site. Font provenance and reuse details are preserved in the manifest and [font notes](../FONTS.md).

## Request a change

Give your agent this folder, the official edition website and approved brand assets. Ask for a focused PR with before-and-after avatar-frame and social-card previews, leaving other events unchanged. The [event guide](../README.md) covers source checks, font rebuilding and verification. Existing editions share this theme/artwork; preserving an older edition's design requires an explicit edition-specific change, not overwriting its ID.
